# Navrayze Falwres

Building **Nav Linux**, a Linux From Scratch based operating system.

## About

Nav Linux is a source-based Linux distribution built from Linux From Scratch and Beyond Linux From Scratch.

The project is designed around a simple idea:

> Learn through building, control through understanding.

Instead of providing a fully preconfigured system, Nav Linux encourages users to build, configure, and understand every major component themselves.
